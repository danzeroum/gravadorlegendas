# audios/

Coloque aqui os áudios ou vídeos que quer transcrever (`.mp3`, `.m4a`, `.mp4`,
`.wav`, `.ogg`/`.opus` do WhatsApp, `.flac`, `.webm`).

No opencode, basta pedir: **"transcreva o áudio reuniao_segunda"** (ou
`/transcrever reuniao_segunda`). As transcrições saem em `audios/transcricoes/`.

Nada desta pasta vai para o git (só este README): gravações e transcrições são
dados pessoais.
